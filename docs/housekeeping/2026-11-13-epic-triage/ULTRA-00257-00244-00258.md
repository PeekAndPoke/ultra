## Decisions for the maintainer

1. **00079 (dynamic operands).** Question: do cross-field rules ship before v1? Options: (a) callback overloads only, with a documented "re-run submit/validate" caveat; (b) overloads + re-validate touched fields on any change (needs debouncing for async rules); (c) declared dependencies; (d) park. Recommend (d) until a project asks: purely additive, so v1 does not force it; if done, (b) with debounce.
2. **00081 (a11y).** Question: whole sweep or a minimal slice first? Options: full ticket (L); slice `aria-invalid` + `aria-describedby` + label `for/id` only (S-M); park. Recommend the slice, split into its own ticket, before v1 (markup only, cheap); the rest post-v1 with 00082.
3. **00082 (UiSelectField).** Question: is the old select stack deprecated before v1? Recommend park post-v1 with a design pass first; it deprecates public API, so decide for the v1 roadmap (ULTRA-00028) whether "SelectField stays as is in v1" is acceptable. Then 00080's select part and 00081's select part park with it.
4. **00239 + 00285 + the key mechanism.** Both depend on moving Klang's key manager (KLANG-00325) into Kraft. Recommend: keep 00239 PAUSED, fold 00285 into it (one ticket, one mechanism) and leave both out of the closing epic, or move them to a new "Kraft keys" epic. 00279 Work 3 (key modifiers) does NOT depend on this: do it now.
5. **00287 (long press).** Question: build before device proof? Options: build `hold: Duration? = null` + `DragHandle.onArmed` and verify on devices with Klang's Looks page; or wait for Klang's report. Recommend: do after 00279, ask Klang-Research to test one Android and one iOS device first (UNVERIFIED claims), name `hold`, pen holds like touch, vibration left to the hook.
6. **00280.** Question: leave the duplicate entry or replace it? Recommend leave it (documented, harmless) and split off the second bug (route link in modal loses navigation), which is a real defect: fix in `doGoBack` with a real-browser row.
7. **00286.** Recommend follow pixi: `Application.renderer` external with `resize(w,h)` and `background.color` (a `dynamic`/Number color), after checking the 8.22.0 d.ts. Alternative: two members on Application (Spross's names).
8. **Epic housekeeping.** 00165 is not Kraft (funktor/ultra common): move it out of 00257. 00280-00282 have no epic. 00239/00284 are parked: closing 00257 means these leave it.
