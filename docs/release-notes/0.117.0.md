# 0.117.0

A Kraft and Streams release, most of it asked for by the projects that use them. Two things break:
`ResponsiveController` takes breakpoints per orientation, and the old Semantic UI drag and drop is gone.

## Before you update

- **Kraft, `ResponsiveController`** (ULTRA-00276): `ResponsiveController(breakpoints = ...)` is now
  `ResponsiveController(portrait = ..., landscape = ...)`, and `Breakpoints.default` is `Breakpoints.portrait` and
  `Breakpoints.landscape`. A positional `ResponsiveController(Breakpoints(...))` still compiles and sets the portrait
  breakpoints only: pass both. A desktop window 768 to 959 px wide is now `Mobile`, not `Tablet`.
- **Kraft Semantic UI, drag and drop** (ULTRA-00265): `DndDragHandle`, `DndDropTarget`, `greenHighlights` and
  `blueHighlights` are gone. Use the new drag and drop in Kraft core (below).
- **Kraft testing, `TestBed`** (ULTRA-00243): inside the block, `app` and `router` are the test app's. A spec with
  its own file-level `val router` now gets the app's router there: rename yours, or use the app's.
- **Streams, `StreamSource.subscriptions`** (ULTRA-00274): it holds subscription entries, not the handlers given.
  Unsubscribe with the returned `Unsubscribe`, not `subscriptions.remove(handler)`.
- **Kraft, `WindowController()`** is deprecated (ULTRA-00268): it returns the shared `WindowController.default`.

## New

**Kraft**

- **Drag and drop in Kraft core**, `io.peekandpoke.kraft.dnd` (ULTRA-00265): drags started from `pointerdown`, drop
  zones registered by components, mouse, touch and pen, Esc cancels.
- **Leave guards** (ULTRA-00266): `guardLeaving { target -> ... }` in a component answers `Proceed`, `Stop` or
  `Ask(confirm)` before every navigation away, also Back and Forward. `router.withoutLeaveGuards { ... }` passes them.
- **`WakeLockComponent`** (ULTRA-00275): keeps the screen awake while mounted.
- **`ResponsiveController` knows portrait and landscape** (ULTRA-00276), and follows rotation.
- **One `WindowController` for the page** (ULTRA-00268), with `isVisible`; `TestWindowController` for tests.
- **`Router.dispose()` and `KraftApp.dispose()`** (ULTRA-00243); TestBed disposes the app after each test.
- **Testing:** the `TestBed` block has `app` and `router` (`router.navToUri`, `router.awaitUri`); `eventually`
  returns its block's value (ULTRA-00247).
- **three.js:** `ThreeJs(paused = ...)` pauses the render loop (ULTRA-00270); constructors and types for groups,
  spot lights, raycasting, textures and shadows (ULTRA-00246).
- **pixi.js:** `createContainer()`, `zIndex`, `sortableChildren`, `Graphics.poly`, and
  `app.followElementSize(element)` (ULTRA-00245, ULTRA-00262).

**Streams**

- **`sampled(every)`** (ULTRA-00267): the latest value at every tick, also unchanged.
- **`smooth()` takes its law as a stream** (ULTRA-00264): a new law continues the motion.
- **One `requestAnimationFrame` per frame** (ULTRA-00269) for `smooth()` and `animTicker()`.

## Fixed

- **Streams:** one handler subscribed twice is two subscriptions (ULTRA-00274); a subscribe that throws leaves
  nothing behind; `ticker` with a very long interval no longer ticks back to back.
- **Kraft router:** `replaceUri` under hash routing lost every `urlParam` change to other subscribers
  (ULTRA-00263); a malformed percent-escape no longer makes route matching throw (ULTRA-00273); `urlParam` keeps the
  path as the address has it (ULTRA-00278); plain clicks on `#/...` links go through the router.
- **Kraft Semantic UI:** a link inside a FadingModal or a DropdownMenu reaches the router (ULTRA-00277).
- **Kraft:** `DisplayType.isNotDesktop` and `isNotMobile` were wrong for `Desktop` and `Mobile`;
  `ResponsiveController` measured the page, not the viewport; listeners left on the window by the popups stage, the
  router and the window controller are removed.

Everything, with the details: [`CHANGELOG.md`, section 0.117.0](https://github.com/PeekAndPoke/ultra/blob/master/CHANGELOG.md).
