# 0.118.0

A large release with many breaking changes, most of them in Funktor. Funktor auth closes an account takeover through
SSO and changes how sign-up works. The file depot becomes its own library, `ultra:depot`, and can encrypt files per
data subject and erase them. Streams and Kraft users get fixes and a few changed behaviours, listed first below.

## Before you update

**Streams**

- **A value written during a publish wins** (ULTRA-00307): a handler that writes to the stream it is told about no
  longer leaves later handlers on the older value, and a handler unsubscribed during a publish is no longer called.
  The lambdas of `map`, `filter` and `fold` must not write upstream; `onEach` may.
- **A stored `null` comes back as `null`** (ULTRA-00309): `persistInLocalStorage` on a nullable stream used to
  restore the initial value. An app that stored `null` to mean "back to the default" now gets `null`.
- **`mapAsync` publishes the latest value's result only** (ULTRA-00308): a mapping that finishes late is dropped.
- **`debounce` and `asFlow`** (ULTRA-00309): `debounce` tells a new subscriber the current value once and reads as
  the last value it passed on; `asFlow()` is conflated, a slow collector gets the latest value.

**Kraft**

- **The message bus no longer replays the last message to a new handler** (ULTRA-00310): an `onMessage` registered
  later gets only messages sent after it. Code that relied on the replay must read the state another way.
- **prismjs and pdfjs load nothing from a CDN** (ULTRA-00306): the files come from npm and are served by the app.
  `PdfJs.librarySource` and `PdfJs.LibrarySrc` are gone; pdf.js is `pdfjs-dist` 4.10.38, the modern build (Safari
  17.4 and later). An app with its own `.css` loader rule excludes these files (`dependency: { not: ['url'] }`), and
  its server serves `.mjs` as `text/javascript`.

**Slumber**

- **Date awakers return null for a zone they cannot read** (ULTRA-00294), where they threw. A nullable field reads
  null, a field with a default takes it, any other fails with `AwakerException`; in a request that is a 400.

**Karango and Monko**

- **Karango: `AqlTypedQuery.LANGUAGE` and `LANGUAGE_RAW` are `internal`** (ULTRA-00228).
- **Monko's query printer walks only known operators** (ULTRA-00228): any other document is printed as one bound
  value, so a query with a misspelt operator no longer shows it in a recorded query.

**Funktor auth**

- **Security: SSO no longer signs in through an address the provider did not verify** (ULTRA-00118). This was an
  account takeover. GitHub sign-in now reads `/user/emails`: an app with its own authorize URL needs the
  `user:email` scope, a GitHub App the "Email addresses" permission. A custom `GithubSsoAuth.RemoteClient`
  implements `getEmails`. Sessions taken before the upgrade survive it: rotate the JWT signing key to end them.
- **Email-first sign-up: the password is chosen when activating** (ULTRA-00231). `AuthSignUpRequest.EmailAndPassword`
  lost `password`, `AuthActivateAccountRequest` carries it, and an activation signs the user in. The resend flow is
  removed (`ActivationRequired`, `POST /auth/{realm}/activate/resend` and what belongs to it). An app's own
  sign-up form, activation page and activation mail need to follow.
- **The display name is chosen at activation** (ULTRA-00289): `AuthSignUpRequest.EmailAndPassword` lost
  `displayName`, `AuthActivateAccountRequest.displayName` is required and must meet `AuthDisplayName`.
  `AuthUserAdapter.activate(user, ActivateUserParams)` has no default; a custom `EmailAndPasswordAuth.Services`
  implements `capEmailVerificationTokens`. Older links of a re-send stay usable for 30 minutes.
- **Security: one-shot tokens are stored as their SHA-256 hash** (ULTRA-00291). The five token record types take
  `tokenHash`; the storage `Adapter` and the Vault `Repo` gain `findByTokenHash`; `Services` loses
  `findSignUpCancelTokenOf` and gains `removeSignUpCancelTokens` and `trimSignUpCancelTokens`. **Links mailed before
  the upgrade stop working**; delete the old one-shot rows of dev databases.
- **An SSO sign-up's profile name must meet `AuthDisplayName`** (ULTRA-00293), else the address's local part is used.
- **Security: an org-selection token signs in once**, also under concurrent use (ULTRA-00295).
- **A burst of sign-ups at a due re-send sends one mail** (ULTRA-00130): `replaceRecordIfClaimedBy` and
  `replaceIfClaimedBy` take `expectedResends`; `Services.replacePendingActivation` takes `(read, next)`.
- **A password is at most 256 characters** (ULTRA-00296). A longer one stored earlier can no longer sign in: reset it.
- **SSO fixes** (ULTRA-00288): GitHub sign-in sends a `state` and accepts the callback only with it.
  `LoginController.AUTH_ACTION_PARAM` is gone, `GithubSignInButton` takes an `action`. Check that GitHub's redirect
  URI still sits under the registered callback URL; build an own authorize URL through `GithubSignInButton`.
- **Password hashes move to the current hasher as users sign in** (ULTRA-00066): `Services` gains
  `passwordNeedsRehash` and `replacePasswordRecord`; `PasswordHasher.needsRehash` is new.

**Funktor rest and core**

- **Security: a request body that does not fit its type is a 400** (ULTRA-00292), and a 500 in production no longer
  carries the exception's message. A client that handled the 500 for malformed bodies now gets a 400.
- **`KtorConfig.isQa`** is `qa`, `qa-<name>` or `qa<digits>` (ULTRA-00225): `qatar` or `qaprod` count as production.
- **`Routes.mountPoint` is gone.**
- **The boot log names the key that signs new tokens** (ULTRA-00178). Nothing to change.

**Funktor insights**

- **Insights runs only in development** (ULTRA-00225): with the switch on outside `dev`, `test` or QA the app
  refuses to boot, and the API answers 404 where insights is not active. Clear the insights depot on upgrade.
- **One switch for the whole app** (ULTRA-00301): `funktor.insights.enabled` replaces the per-mount `InsightsConfig`.
  `instrumentWithInsights(app)` takes the `App`; move `insights { enabled = ... }` into `funktor { }`.
- **Vue GUI** (ULTRA-00190): an app that generates the TS SDK declares `@lucide/vue` 1.71.0, `prismjs` 1.30.0 and
  `@types/prismjs` 1.26.6; the generator prints the `pnpm add` line.
- **Query values are recorded again** (ULTRA-00171). A repository that stores secrets is built on
  `driver.withholdingQueryValues()`; funktor's own do so. An app's own such repository needs that one line.
- **The record endpoint and the list show records only** (ULTRA-00304); other files of the insights depot are a 404.
- **`TemplateInsightsCollector` and the "View" tab are gone.**
- **`FunktorInspectUi`** (ULTRA-00198): the new `insightsApi` parameter comes before `kronos` and `customInternals`;
  pass those by name.

**Funktor, removed**

- **The `staticweb` module is gone** (ULTRA-00305), with all webjars and `funktorStaticWeb()`. `funktor:all` no
  longer brings `ktor-server-html-builder`, `kotlin-css`, `ultra:html` and `ultra:semanticui`: an app that uses
  them declares them itself.

**Depot**

- **The depot moved to `ultra:depot` and `ultra:depot-s3`** (ULTRA-00311). Packages
  `io.peekandpoke.funktor.cluster.depot...` are `io.peekandpoke.ultra.depot...`, the S3 repository is
  `io.peekandpoke.ultra.depot.s3`. `funktor:cluster` brings `ultra:depot`; an app using `AwsS3Repository` adds
  `ultra:depot-s3`.
- **Every write names its data subject, and files carry metadata** (ULTRA-00311): `putFile(subject, path, content,
  meta)`, with `DepotRepository<T>` typed by the kind of subject and `DepotSubjectId.system` for files of no person.
  `getContent` returns a sealed `DepotContent` (`Found`, `NotFound`, `Shredded`). `DepotPutFileOptions`, `DepotMeta`
  and `DepotFileContent` are gone. S3 tags are no longer written or read. `.meta` is a reserved first path segment.
  `DepotUri` keeps a path as it is, and a repository name has no `/` (ULTRA-00314).
- **One path check for every repository** (ULTRA-00304): `.` and `..` segments and a symlink out of the root are
  refused with `DepotInvalidPathException`. Files reached through such a symlink are no longer reachable: point the
  repository at the link's target.
- **`DepotFacade` refuses two repositories on one folder or bucket, or with one name** (ULTRA-00311).

## New

- **Depot: encrypted repositories with erasure** (ULTRA-00311): `EncryptingDepotRepository` encrypts each file with
  a key of its own, wrapped by its data subject's key; `shred(subject)` erases that key and with it the subject's
  files. `SignedDepotRepository` stores files with a keyed hash, and `verify(path)` finds damage and tampering. Key
  stores for Karango and Monko come with `funktor:cluster`. Read the limits on the
  [cluster page](https://peekandpoke.io/ultra/funktor/cluster/): a database backup still holds an erased key until
  it expires, and metadata is plain.
- **Streams: configurable operators take their config as a stream** (ULTRA-00271): `quantize`, `fallbackTo`,
  `history`, `ticker`, `debounce`, `smooth`.
- **Kraft: `addons-visnetwork`** (ULTRA-00198), a vis-network graph component. `PrismAql` for the prismjs addon.
- **Funktor inspect: the insights GUI for Kraft** (ULTRA-00198), on par with the Vue one.
- **ultra/security: `SecretGenerator`** (ULTRA-00067): tokens, strings and temporary passwords from a CSPRNG.

## Fixed

- **Streams: reads without a subscriber** (ULTRA-00302): `distinct()`, `cutoffWhen()`, `filter()` and `indexed()`
  returned a stale value; they now read the source.
- **Streams:** `smooth` told a new subscriber its first value twice; `ticker(0)` ran frames back to back (ULTRA-00309).
- **Kraft prismjs:** lazily loaded languages and plugins failed in strict bundles; Prism no longer highlights the
  whole page.
- **Depot:** `FileSystemRepository.listItems(path, limit)` listed the root, whatever the path (ULTRA-00304).
- **Funktor auth on Karango:** overlapping writes of one auth record no longer end in a 500 (ULTRA-00130).
